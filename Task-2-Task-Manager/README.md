\# TaskFlow – Dynamic Task Manager \& Productivity Tracker



A web-based task management application designed to help users organize tasks, track progress, and manage daily productivity.



\## Features



\- Add new tasks.

\- Edit existing tasks.

\- Delete tasks.

\- Mark tasks as completed or active.

\- Search tasks.

\- Filter tasks by status.

\- Organize tasks by category.

\- Dashboard statistics for task progress.

\- Automatic task saving using browser localStorage.



\## Technologies Used



\- HTML5

\- CSS3

\- JavaScript

\- Browser localStorage



\## Getting Started



1\. Clone or download this repository.

2\. Open the `index.html` file in your browser.

3\. Start creating and managing your tasks.



No backend or account registration is required.



\## Data Storage



Tasks are stored locally in the browser using localStorage. Data is specific to the browser and device being used.
